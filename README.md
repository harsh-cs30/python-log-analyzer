
# Python Log Analyzer

A beginner-friendly cybersecurity project built with Python.

## Features
- Reads security log files
- Counts failed login attempts by IP address
- Detects suspicious login activity
- Generates security alerts
- Saves a security report

## Technologies
- Python
- VS Code
- Git and GitHub

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   python main.py

## Disclaimer
This project uses fictional sample logs for educational purposes.
